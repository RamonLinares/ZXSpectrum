📖 Sinclair BASIC Reference

Quick Commands

  • RUN : Run the program in memory
  • LIST : Display the BASIC program lines
  • CLS : Clear the screen
  • BORDER n : Set border color (0 to 7)
  • PAPER n : Set background color (0 to 7)
  • INK n : Set text color (0 to 7)
  • BEEP duration, pitch : Play 1-bit sound

Example BASIC Program

10 BORDER 0: PAPER 0: INK 6: CLS
20 FOR X=0 TO 255 STEP 4
30 PLOT X, 96 + 50*SIN(X/20)
40 NEXT X
50 BEEP 0.5, 10: RUN
